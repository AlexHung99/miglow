# 宮闈浮生位階、晉降與俸祿資料規格 v1.1

本文件是 `game.ranks` 的正式種子資料依據，來源為原始文件 `位階/妃嬪位階.md`、`位階/皇子位階.md`、`位階/帝姬位階.md` 與 `遊戲規則/銀兩獲得.md`。除本文件標示為「待確認」者外，不得由程式自行推測或重平衡。

## 1. 共通晉降規則

- 能力值採 0～1000：體質 `vitality`、容貌 `appearance`、心計 `strategy`、福氣 `luck`。
- 晉升必須同時滿足目標位號的威望、能力、已結算事件次數、活躍度、自戲字數及名額條件；未列出的條件視為無門檻，不可解讀為 0 以外的隱藏要求。原始文件的「主線次數」因 Web 版已取消主線模組，v1.1 統一解讀為角色成功完成且已結算的事件次數 `settledEventCount`。
- 每次規則結算若任一必要條件不符，角色降至其當下「全部條件皆符合」的最高品級；同品級的位號由有權限管理員依劇情及空缺指定。
- 有限名額以交易鎖檢查。正二品以上可居主殿。
- `＊` 寫入 `is_lead=true`。原文稱「為尊」不代表限額；只有明列「限一／限二／限三／限四」或「各一」才寫入 `capacity`。
- 新角色初始銀兩固定為 0；初始能力由獲准的建角起始位號決定，後端不得接受前端自訂數值。
